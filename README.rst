Benchmark for Time Series Foundation Models (TSFM)
==================================================
|Build Status| |Python 3.10+|

This benchmark evaluates the performance of various time series foundation models (TSFM) on a range of datasets and tasks. It is built using the `benchopt` framework, which provides a standardized way to compare different solvers and algorithms on a common set of problems.

The goal is to provide a benchmark that evaluate the models on:

- Classification
- Forecasting
- Anomaly Detection

With diverse modalities (univariate, multivariate, EEG, etc.) and varying sequence lengths.

Install
--------

This benchmark can be run using the following commands:

.. code-block::

   $ pip install -U benchopt
   $ git clone https://github.com/benchopt/benchmark_tsfm
   $ benchopt run benchmark_tsfm

Apart from the problem, options can be passed to ``benchopt run``, to restrict the benchmarks to some solvers or datasets, e.g.:

.. code-block::

	$ benchopt run benchmark_tsfm -s solver1 -d dataset2 --max-runs 10 --n-repetitions 10


Use ``benchopt run -h`` for more details about these options, or visit https://benchopt.github.io/api.html.

Plots
-----

In addition to benchopt's default plots, this benchmark ships a `custom plot
<https://benchopt.github.io/stable/user_guide/add_custom_plot.html>`_ in
``plots/critical_difference_diagram.py`` that renders a
`Critical Difference Diagram <https://mirkobunse.github.io/CriticalDifferenceDiagrams.jl/dev/>`_
(Demsar 2006) for each evaluated metric, comparing the mean rank of every
solver across datasets. Solvers connected by a horizontal bar (clique) are not
significantly different under a pairwise Wilcoxon sign-rank test with Holm
correction.

Select it explicitly with:

.. code-block::

    $ benchopt plot benchmark_tsfm -k critical_difference_diagram

It also appears in the HTML report drop-down generated by ``benchopt plot``
(default).
